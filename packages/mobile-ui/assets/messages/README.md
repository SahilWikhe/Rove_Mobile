# Messaging assets

`messages.svg` is the original driver Figma `4:252` message icon export
(file `1IzXAu67Sogja8SvfPtOlB`, Messages screen `4:2`, retrieved September 11, 2026).
`messages.png` is its transparent 96-pixel native render, tinted by the selected tab.
`avatar.png` reuses the generic Figma avatar already in rider `assets/tracking/driver-avatar.png`.
It is decorative, not a profile photograph. Temporary export URLs are not runtime dependencies.
