# Driver account avatar

`avatar.svg` is the original export of driver Account avatar node `4:111` in
[Rove Driver App](https://www.figma.com/design/1IzXAu67Sogja8SvfPtOlB/Rove-Driver-App?node-id=4-106).
`avatar.png` is its transparent 4× rasterization for React Native Image.
The shared profile component supplies the source design's 56-unit circle and brown background.
This is a decorative generic avatar, not a photograph of the signed-in driver.
