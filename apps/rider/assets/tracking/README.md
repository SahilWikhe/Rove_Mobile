# Rider tracking assets

The generic driver avatar is exported from node `6:73` in the supplied
[Rove rider tracking frame](https://www.figma.com/design/8S3vQl4P3bVTLSKgxPDghv/Rove-Ride-App?node-id=6-20).
The SVG retains the original export; the transparent PNG is a 4× rasterization for React Native Image.
It is decorative, not a photograph of the assigned driver.
